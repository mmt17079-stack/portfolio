## 🛠️ Stack Technique du Portfolio

* **Frontend** : HTML5 sémantique, CSS3 moderne (animations, variables CSS, backdrop-blur, design responsive), JavaScript ES6+
* **Interactions** : Filtrage dynamique multi-domaines, modale interactive avec aperçu d'images, indicateur de progression de défilement, effet parallaxe et menu mobile responsive.
* **Assets** : Toutes les captures d'écran et bannières sont stockées localement dans le dossier `assets/` pour un déploiement autonome sans dépendance externe.
